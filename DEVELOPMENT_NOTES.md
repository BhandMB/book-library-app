# Library App Usability Checklist

Use this checklist when updating the user interface.

- Provide clear loading, empty, success, and error states for book operations.
- Check form labels, keyboard navigation, and visible focus indicators.
- Validate user input before sending requests while still handling API validation errors.
- Make API failures understandable without exposing internal server details.
- Confirm layout behavior at narrow and wide viewport sizes.
- Verify links, navigation, and create/update/delete flows after UI changes.
