# Book App Error Message Content

> Created: 2026-11-14

Define user-facing messages for validation, not found, conflict, unauthorized, forbidden, network timeout, and server errors. Keep messages actionable, preserve entered form values when safe, and never expose stack traces or internal server details.

## Review standards

- Inspect the current code and configuration before recording implementation findings.
- Separate confirmed behavior, open questions, and recommendations.
- Include reproducible test steps and expected results before execution.
- Record test outcomes or measurements only after they have actually been produced.
