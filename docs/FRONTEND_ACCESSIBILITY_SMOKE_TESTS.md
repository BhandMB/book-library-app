# Frontend Accessibility Smoke Tests

Run these checks on the main screens and forms:

- [ ] Navigate interactive controls using only the keyboard.
- [ ] Confirm focus indicators are visible.
- [ ] Verify inputs have associated labels.
- [ ] Check heading hierarchy and meaningful link text.
- [ ] Confirm images have appropriate alternative text or are decorative.
- [ ] Ensure errors are conveyed by text, not color alone.
- [ ] Check text contrast and zoom at 200%.
- [ ] Verify dialogs and menus manage focus appropriately.
- [ ] Check that dynamic status updates can be understood by assistive technology.

Record the pages checked, browser, and any issues found. This file is a test checklist, not an accessibility certification.
