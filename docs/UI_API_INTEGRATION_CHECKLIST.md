# UI and API Integration Checklist

- Confirm the API base URL is configurable for local and deployed environments.
- Show a loading state while requests are pending.
- Show a helpful empty state when no books match the current query.
- Display actionable messages for validation, network, and server errors.
- Refresh the visible list after successful create, update, or delete operations.
- Prevent duplicate submissions while a mutation is in progress.
- Verify behavior when the API is unavailable or returns an unexpected payload.
