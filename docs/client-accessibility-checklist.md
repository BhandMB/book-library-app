# Client Accessibility Checklist

- [ ] Every interactive control has a visible label or accessible name.
- [ ] Keyboard focus is visible and follows a logical order.
- [ ] Form validation errors are associated with the relevant field.
- [ ] Loading and empty states are understandable without color alone.
- [ ] Text remains readable when browser zoom is increased.
- [ ] Buttons and links have clear, action-oriented text.

Run this checklist for the main list, search, add, edit, and error flows before release.
