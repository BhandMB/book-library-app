# Frontend Regression Checklist

After a UI change, verify:

- The app loads without console errors.
- Navigation and page refreshes behave as expected.
- Book lists render correctly with data, no results, and API failures.
- Create and edit forms handle valid, invalid, and incomplete input.
- Delete actions require clear intent and update the UI after success.
- Loading and disabled states prevent confusing repeated actions.
- Layout remains usable on desktop and mobile-sized screens.
