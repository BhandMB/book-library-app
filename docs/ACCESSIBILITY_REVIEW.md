# Accessibility Review

- Give every form control a programmatic label.
- Ensure interactive elements can be reached and operated with a keyboard.
- Keep focus indicators visible during keyboard navigation.
- Use headings in a logical order and descriptive link text.
- Do not rely on color alone to communicate errors or success.
- Provide meaningful alternative text for informative images and empty alternative text for decorative images.
- Check text contrast and layout at narrow viewport widths.
- Re-run this review when navigation, forms, or shared components change.
