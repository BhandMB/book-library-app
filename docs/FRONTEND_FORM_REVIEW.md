# Frontend Form Review Checklist

- [ ] Labels clearly identify every input.
- [ ] Required fields and constraints are communicated to users.
- [ ] Client-side validation improves usability without replacing server validation.
- [ ] Invalid values produce clear, actionable feedback.
- [ ] Submission progress is visible and repeated submission is controlled.
- [ ] Server validation errors are displayed safely.
- [ ] Focus moves appropriately when validation fails, where applicable.
- [ ] Successful submission confirms the outcome and updates the view.
- [ ] Cancel/reset behavior is predictable.
- [ ] Tests cover valid input, invalid input, and server/network failure.
